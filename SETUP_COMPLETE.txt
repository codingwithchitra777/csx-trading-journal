🔧 TROUBLESHOOTING
═════════════════

Service won't start?
    → Check logs: journalctl -u csx-trading-journal -n 100
    → Check Python path exists
    → Check permissions on /workspaces/csx-trading-journal

Service crashes frequently?
    → Check logs for errors
    → Check Firebase credentials
    → Check Telegram token

Can't find logs?
    → Try: journalctl --since "1 hour ago" -u csx-trading-journal

Service not starting on boot?
    → Check enabled: sudo systemctl is-enabled csx-trading-journal
    → Re-enable if needed: sudo systemctl enable csx-trading-journal


💡 TIPS & TRICKS
